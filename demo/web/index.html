Build on it

Yoke is one Rust crate with no daemon, no HTTP API and no subagents. The loop owns no UI and no storage, so you can put your own face on it.

typesmessages, parts, requests, usage
providers & toolsone dialect each; read, write, edit, bash
loopmodel → tool calls → results → model
consumersthe TUI, plain mode, and this demo

Each layer is replaceable. This page drives the same loop through a PTY; it does not fork it.

embedding the loop
use yoke::{loop::run, providers, tools};

// A consumer supplies the provider, the tools and a sink for events.
let provider = providers::make("groq", "qwen/qwen3.8-27b")?;
let mut registry = tools::Registry::default();
registry.add(MyTool); // name, schema, run()

run(Request::new(system_prompt, memory, conversation), provider, registry, |event| {
    // StreamEvent::Text, ToolStart, ToolOutput, ToolEnd…
    app.apply(event);
}).await?;

The current API is in the repo; this snippet follows examples/minimal.rs as the library split lands.

Install

Rust 1.80+ and a terminal. Then yoke login groq, or set GROQ_API_KEY.

cargo install --git https://github.com/nottherealsanta/yoke

Keys & tokens

Locally, use any provider you like with your own key. Nothing leaves your machine except the request to that provider.

01

BYO key always works. yoke login groq (or --provider openai, codex, and so on) keeps the key in your own credential store.

02

The hosted demo is Groq only. It runs one model with only read/write/edit enabled, so we can keep it small, cheap and safe.

03

We provide limited free demo tokens. Rate-limited per visitor and per day; bring your own key if you hit the cap. No account, no sign-up, no tracking.

Built in Rust. One binary, one loop, one visible timeline.

Sandbox. Demo sessions run read/write/edit only, confined to a temporary directory with no memory file, deleted on disconnect.

Privacy. Prompts and file contents are sent to Groq to produce a reply. We don't store conversations, accounts or API keys.

Rate limits. Demo tokens are capped per visitor and per day; sessions end after a few quiet minutes.
