# Meadow

A tiny, made-up project used for the Yoke demo. It is small on purpose: the
files fit on one screen, so you can watch every read and edit.

```
README.md          this file
notes.txt          meeting notes, with a few typos
todo.md            the team's checklist
pyproject.toml     just enough Python project metadata
src/summarize.py   reads data/sessions.csv and prints a summary
data/sessions.csv  one week of made-up numbers
```

Run it from this folder:

```sh
python3 src/summarize.py
```

**Suggested prompts**

- `read notes.txt and fix the typos`
- `find the bug in src/summarize.py`
- `what files are here?`
- `add a busiest_day() function to src/summarize.py`

Everything here is scratch. The folder is deleted when the demo session ends.
